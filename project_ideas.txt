PROJECT TITLE:
AI Sales Follow-Up Manager (Powered by n8n – Local First Version)

====================================================================

OVERVIEW:
This project is a locally runnable AI-powered Follow-Up Automation Manager 
designed for sales professionals.

Instead of building a full frontend dashboard initially, the system runs 
entirely inside n8n, which acts as both:
- Workflow engine
- Temporary user interface

Users simply:
1. Install n8n locally
2. Import the provided workflow JSON
3. Configure credentials
4. Start generating follow-ups

No custom frontend required (Version 1).

====================================================================

CORE OBJECTIVE:
Reduce time spent writing repetitive follow-ups by providing:

- Personalized Email drafts
- SMS drafts
- LinkedIn connection messages
- Editable outputs before sending

All generated using AI + structured templates.

====================================================================

FIRST-TIME USER EXPERIENCE:

STEP 1: Install n8n Locally
Run:
npm install n8n -g
n8n start

STEP 2: Import Workflow JSON
Upload:
ai-sales-followup-manager.json

STEP 3: First-Run Setup
On first execution, user chooses:

1) Connect Existing Google Sheet
2) Create New Google Sheet

====================================================================

CUSTOMER DATABASE OPTIONS:

Option A: Connect Existing Sheet
User provides:
- Google Sheets link
- API access
- Worksheet name

Required Fields:
Customer ID | Name | Email | Phone | LinkedIn | Company | Notes

Option B: Create New Sheet Automatically
Workflow:
- Creates a new Google Sheet
- Creates required columns
- Stores Sheet ID for future use

====================================================================

SYSTEM FLOW:

1. User opens n8n
2. Runs workflow
3. Chooses:
   - Existing Customer ID
   - Create New Customer
4. Workflow:
   - Fetches data from Google Sheets
   - Applies template or AI generation
   - Returns editable drafts

All drafts appear inside n8n execution output.

====================================================================

FOLLOW-UP OPTIONS:

User selects:
- Preset Template
- AI Generate New Template

Outputs:
1) Email Draft (Editable)
2) SMS Draft (Editable)
3) LinkedIn Message (Editable)

Sending Options:
- Manual copy-paste
- Automated via SMTP / Twilio / API (optional)
